# {{PROJECT_NAME}}

Monorepo generated by **agent-devex**.

- `contracts/agent_pay_integration` — Soroban escrow (`deposit`, `execute_payment`, `refund`) plus AgentPay / AgentGuard
- `server/` — MCP backend (Node.js or Python)
- `agent/` — compact MCP server (`settle_and_execute`)

## Start

```bash
cp .env.example .env
# fill STELLAR_SECRET_KEY and contract ids

stellar contract build --manifest-path contracts/agent_pay_integration/Cargo.toml
agent-devex deploy --project-dir . --network testnet
```

### Node MCP (`server/`)

```bash
cd server && npm install && npm run build
npx tsx src/index.ts
```

### Python MCP (`server/`)

```bash
cd server && pip install -r requirements.txt
python main.py
```
