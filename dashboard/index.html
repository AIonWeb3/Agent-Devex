AIonWeb3 · Stellar · MCP

Ship AI-to-chain payments in one CLI.

Agent-Devex scaffolds a Soroban contract with AgentPay settlement and an MCP server so any LLM can invoke settle_and_execute on testnet.

See the workflow GitHub

The problem

Teams spend weeks wiring smart contracts, secret handling, and Model Context Protocol servers before an agent can take a single paid action on-chain.

Core workflow

  1. init — generate contract + MCP monorepo
  2. doctor / validate — confirm toolchain and layout
  3. deploy — build WASM and publish to Stellar
  4. status — confirm contract id for the agent

Why this wins a pitch

Minutes, not weeks

Scaffold contract + MCP with one command instead of a custom integration sprint.

Payments first

AgentPay settles a positive amount before the agent mutates on-chain state.

LLM native

settle_and_execute is an MCP tool Cursor and Claude Desktop can call today.

Preview the MCP tool

Onboarding checklist

  1. Install Rust stable and run agent-devex doctor
  2. agent-devex init my-agent --lang ts
  3. Copy .env.example → .env (never commit secrets)
  4. Deploy with STELLAR_ACCOUNT set, then start the MCP server

When nothing is deployed yet

No contract id? That is expected on a fresh laptop. Run agent-devex doctor then init. The CLI prints next steps instead of a blank failure.
