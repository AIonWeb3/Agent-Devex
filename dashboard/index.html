AIonWeb3 · Stellar · MCP

Ship AI-to-chain payments in one CLI.

Agent-Devex scaffolds a Soroban contract with AgentPay settlement and an MCP server so any LLM can invoke settle_and_execute on testnet.

See the workflow GitHub

The problem

Teams spend weeks wiring smart contracts, secret handling, and Model Context Protocol servers before an agent can take a single paid action on-chain.

Core workflow

  1. init — generate contract + MCP monorepo
  2. doctor / validate — confirm toolchain and layout
  3. deploy — build WASM and publish to Stellar
  4. status — confirm contract id for the agent
